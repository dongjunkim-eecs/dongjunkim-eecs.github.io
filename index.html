Undergraduate researcher in Audio AI at Kangwon National University (Electronics Engineering, 4th year). I work on efficient deep learning for acoustic signal processing on edge devices — building models small enough to run on microcontrollers without sacrificing accuracy.

Preparing to apply for PhD programs in the US (Fall 2026). Interested in neural network quantization, knowledge distillation, and on-device continual learning.

Interest of Fields

Efficient Deep Learning for Edge Deployment

Quantization-aware training and knowledge distillation for deploying audio classifiers on MCU-class hardware with extreme memory constraints. My QAD framework combines adversarial training to close the accuracy gap on edge targets.

Underwater Acoustic Target Recognition

Classifying ship-radiated noise using spectrogram-based deep learning. Current architecture focus: shuffleFAC, a frequency-aware convolutional network designed for low-memory inference.

HW/SW Co-design for On-device AI

Exploring how custom operators interact with compiler-level optimizations — operation fusion, SRAM buffer sizing, and memory layout — on platforms like Jetson Orin Nano and STM32.
