Edge AI
Real-Time Edge AI System for CNC Machine Chatter Detection
Developed an end-to-end Edge AI monitoring pipeline for CNC anomaly detection, operating entirely on-device without cloud dependency. Trained an ultra-lightweight ShuffleFAC model, deployed it on a Raspberry Pi 4, and demonstrated real-time classification of abnormal chatter using acoustic data collected directly from a CNC machine.
